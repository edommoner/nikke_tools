# 外部参照のbuff倍率とDoT係数

ABI `0x50455653` の共通Slangへ `scaling: stack_count` と `scaling_ref` を接続しました。有限buffは初回の名前通知前に参照を保持し、再発動ではstack/name通知の子が終わってから取り直します。無期限buffと保持時に未登録だった参照は現在値を読みます。外部倍率では自身stackや受信者stackを二重乗算しません。

参照の優先順位は、所有者の登録済み資源（0を含む）、同じ所有者の最初の生存carrierです。資源の整数化はsoftware binary64のビットで0方向へ切り捨て、int64へ先に狭めません。負数・0・1e30も倍率として保持します。全演算はCUDA／Metal共通のsoftware binary64で、Metalのfloat32へ代替していません。featherの生存数は未接続です。

外部参照DoTは登録時の参照をcarrierのstackとして保持し、未登録時は1です。max_stack=1の更新は保持値を維持し、stack型は更新ごとに参照を取り直します。参照値をmax_stackへ丸めません。期限後の再登録は新しい値を保持します。係数を発動ごとに固定し、0係数は命中数参照前に省略します。既存の対象順・世代・同名時計の規約は維持します。

## 共有配置

入力の4-word参照packetを命中数と倍率で共有します。

| word | 内容 |
| --- | --- |
| 0 | bits 0–1 命中数mode、bits 2–3 倍率mode（1=現在値、2=有限保持、3=DoT保持） |
| 1 | bits 0–8 命中数key+1、bits 9–17 倍率key+1 |
| 2 | bits 0–7 命中数name、bits 8–15 倍率name |
| 3 | 予約0 |

出力の余白から1536 wordsを使い、512 carrierの保持フラグとbinary64を保存します。入力57,344・出力65,536 wordsのstrideとRuntime／Definition配列サイズは増やしていません。既存Definition.flagsの数値4のbitで、倍率を持たないscalarの参照探索を省きます。毎回探索する `gpu/benchmark_reference_scale_lookup.slang` と、共通の全ケース・全出力バイトを比較します。CUDA/MSLを別々に編集しません。

## CPU互換層の修正

元のpinnedソースは変更していません。`app/reference_count_runtime.py` は名前キャッシュを、有効一覧のidentity・長さ・構造版が変わったときに無効化します。登録前の保持取得が空の一覧をキャッシュし、append後も自己参照が永久に0になる不具合を修正します。0/0/0から10/20/30への修正と、値だけの更新でキャッシュ一覧を再利用することを単体検査します。

`app/reference_health_runtime.py` は外部参照最大HPを持つ場合、外側の実行境界で現在HPを上限へ収め、HP率と境界通知を更新します。名前／stack通知の子はHP付与より前に完了します。付与途中の一時的なHP率で境界通知を出しません。境界通知の子がさらに参照を変えた場合、最後に再通知を抑えて最終HP率を反映します。GPUは同じ実行境界へ継続フレームを置き、子通知を既存の明示スタックで完了させます。
