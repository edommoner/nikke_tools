# 条件付き武器変更と進入待ち（共通本体へ試験接続）

HP由来攻撃力の実編成検証で、ラプラス：アルティメットヒーローの通常／成長180秒がGPU変換時に拒否されました。134条件と旧130条件は検証できましたが、全136条件の成功ではありません。2条件を除外して母数を減らしません。

この武器変更は `full_charge_fire`・予熱5スタックで発動し、時間期限を持たず120発で終了します。元CPUの武器変更条件は通知時の発動条件であり、予熱を直後に除去しても変更状態は続きます。GPUにも発動条件・変更状態・発数終了の処理がありますが、アダプターの無期限条件付きモードのガードが残っています。

ガード1行だけを外した別コピーのアダプターで変換を試すと、次は `pack_mode` が進入待ちの未実装として拒否しました。この最初の診断ではGPUを実行せず、本体の両ガードを保持しました。失敗記録は `portable-conditional-mode-candidate-compile-finding.json` です。

元の `_DELAYS` にはこのモードの `entry_delay=0.39` があり、変更状態を物理的に処理し始めた最初のtickから待ちます。発動した通知時刻から単純に0.39秒を足す処理ではありません。元 `_tick_weapon_change` は進入待ちを先に処理し、待ちが終わってから変更武器の弾倉と発射ループへ進みます。待ちの完了でチャージ状態をreadyへ戻し、チャージを無料で経過させません。`entry_reload` の速度補正付き待ちとは区別します。

共通実行器へ接続する前に、初回tickと発動の時刻差、0・正の待ち、進入待ち中の解除／切替／更新、チャージと連射、弾倉の初期化時刻、発数終了、待ちと有限期限の競合、再進入を元CPUで観測します。既存のpost-reload時計を転用して意味を変えず、必要な状態を明示し、生成初期化器を更新します。入力の未使用モード領域へ数量・有無を入れる場合は版と生入力検査も必要です。

まず別コピーで元CPUと一致させ、ラプラスの全効果を含む2実編成を確認してから本体へ採用します。その後に旧3539入力・旧134編成の保持、全体検査、短いCUDA検証、全検証・転送後の効率測定を行います。通常画面はCPUで、全キャラ認証は未完了です。

別コピーの360ケースは時計・弾倉・発数まで元CPUと一致し、旧3539入力の全出力も保持しました。しかしラプラスの180秒では本人の総ダメージと進入完了時のcharge-start記録に差が残りました。1～20秒の新しい診断入力ではダメージが一致し、攻撃・HP由来加算も一致しました。元CPUの180秒hit記録から、2回目以降のB3追加ダメージが原因候補です。元の `_fire_pending_burst_dmg` は、遅延した `bonus_damage` の `scaling:stack_count` を全バースト発動時の参照値で係数へ掛けてから1回丸めます。既存GPUのpending経路は生の係数を使い、この参照をまだ反映していません。通常スキルの「参照回数だけ発射」と同一にしてはいけません。入力・readbackと全差分を保持して診断を続けており、本体には未採用です。


最終の別コピーで、進入待ち400例、B3参照120例、入力拒否10例、ラプラス2実編成、旧3539入力の全出力保持が成功しました。条件付きモード・待ちとpending係数の共通Slangを本体へ反映し、ABIを `0x50455672` としました。固定ソースでの本体の全体回帰・全体ゲート・CUDA確認・効率測定はまだ未完了です。

進入待ちはMODE領域の末尾4 wordsへ数量・有無・予約語を格納します。未指定と明示ゼロは区別し、元CPUがゼロ待ち完了でも更新する物理時計を保持します。Runtimeへ5人分の進入時計を追加し、初期化器を再生成しました。最終時計10 wordsは既存出力余白に置き、この機能が存在する入力だけで出力します。入力86016／出力159744 wordsを維持し、既存入力の出力余白は変えません。待ち中の弾倉確定、同一セッション更新、解除・切替・再進入、待ちより先の期限を元CPUと比較しています。

B3の参照付き追加ダメージは、発動時には生の係数をキューへ保持し、全バースト時に現在の参照値を掛けてから一度丸めます。ゼロ・欠落ではパケットを出さず、処理済みキューの件数は記録します。参照が発動後に増減する場合と、256を超える係数倍率も含めています。通常の参照ヒット数の上限とは分けます。原CPUのコントローラーと元のpending発射を使う成分120例に加え、ラプラスの全効果を含む通常・成長180秒で確認しました。
