# 通知候補の共通索引と被弾回数

通知ごとの定義候補を256ビットのマスクに梱包し、通常の通知探索を共通Slangの索引へ接続しました。64通知×8ワードを既存の入力余白へ格納するため、ABIは `0x5045564C` へ更新しますが、入出力の幅は各53,248ワードのままです。Runtimeや効果実体ごとの永続領域は増やしません。

候補は静的な通知記述から作ります。GPUは全マスクを通知記述と照合し、欠落・余計な候補・定義数を越えたパディングビットをエラー64で拒否します。CPUで発動順・カウンター・対象・戦闘時刻を計算して渡す経路ではありません。

GPUは候補行を元の定義順に取得し、その後の発動者・タグ・段階・条件・回数・予算の判定を従来通り実行します。強制スキルの直接／選択実行とタイマーの経路は従来の探索を保ちます。複数の同一通知記述がある場合の発動回数も既存のCPU本体と共通GPUの規約を維持します。異なる閾値2・3の記述を、独立した単一発動と仮定した最初の期待値はCPU本体の観測と異なりました。この仮定を修正した記録を `research/portable-event-candidate-assumption-audit.json` に残しています。ゲーム内仕様の新規確認やCPUの修正とは扱いません。

`received_hit_count:N` も既存の被弾通知と共通カウンターへ接続しました。閾値1・2・3・10・20・40、発動者別の蓄積、発動上限、無敵中のゼロダメージ、条件不成立中の蓄積、複数／重複記述を検査します。追加14ケースには31/32・63/64・127・255行の境界と、通知候補に含まれない255行目の強制実行も含めます。

`scripts/verify-portable-event-index.py` は全走査の制御版へGPUソース選択だけを切り替え、通常の検証器・同じ入力・期待値・CPU独立参照を再利用します。全正例・拒否例について全出力ワードと各比較リストの一致を検査します。制御用の計算本体やCUDA／Metal別の期待値は複製しません。

全キャラの全効果・全変種のGPU認証と通常画面の接続は未完了です。通常画面はCPUを継続します。

初回の並行コンパイルでは実編成のコンパイル待ち300秒、HTTPでは従来の120秒上限に達しました。失敗を `portable-event-index-roster-compile-timeout.json` と `portable-event-index-api-timeout.json` に保存しています。実編成はパイプライン生成後の再実行で46/46がCPU本体と一致しました。

HTTPのMetal開発経路は、ソース生成2×90秒・コンパイル待ち300秒・GPU待ち120秒を包む630秒上限、検証クライアントは660秒へ修正します。CUDAと通常CPUの上限は120秒のままで、既定のMetalバックエンドを含めた範囲を単体検査します。コンパイル待ちをGPU計算時間や速度向上として計上しません。

最終回帰は739正例・88拒否、全走査制御版との全出力一致、49単体、サーバー単体8件、全23候補の46実編成、固定8編成、203武器、203装備、HTTPの追加5ケースを含む経路で成功しました。数値34,874件と最初の実証4件は、依存ソースと検証器のハッシュが前段の実機成功記録から変わっていないことを確認しています。今回それらを再実行したとは扱いません。

固定コミット `0ef99241e2c175ff6661241f375d1c1a48de95ee` はWindowsのRTX 3070 Tiで低優先度・120秒上限・1回だけ実行し、50.382秒で成功しました。共通ソース・入力・全出力・検証コード・全ステータス・全ケース・全CPU比較リスト・既知差異3種類がMetal版と一致しました。生成CUDA／MSLも位置情報・改行・標準includeパスだけの正規化で一致しています。元の作業状態と既存GPUサービスを維持し、検証プロセスの残存は0です。要約 `windows-portable-combat-v28.json` と生成物の照合 `portable-generated-v28-comparison.json` を保存しています。既知のCPU差を修正・解消したという意味ではありません。

固定負荷は255味方実体＋1敵補正、20秒・1,201射撃の16入力です。他の本チャットの検証終了後、全走査版と索引版を順番に各3回実行し、入力と全出力のハッシュが一致しました。GPU中央値は3.149085秒から2.566743秒、約18.5%短縮しています。試行範囲は3.144578〜3.150379秒と2.562708〜2.569956秒で重なりませんが、実編成全体の速度や外部のデスクトップGPU処理を排除した測定ではありません。詳細は `portable-event-index-benchmark-before.json` と `portable-event-index-benchmark-after.json`、集約は `portable-combat-checkpoint.json` を参照してください。
