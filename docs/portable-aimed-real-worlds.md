# 全定義の実編成と物理照準の接続

ビスケット、リトルマーメイド、リリーの既存の完全な編成を、割り込み対象／罰則部位の2world、各3秒／30秒へ接続しました。キャラ効果・成長・装備・味方の定義を削除せず、各70／79／68定義を一度ずつbindします。新しい敵ダメージ計算を作らず、共有Slangの物理着弾・敵効果・状態実行器を使用します。

公開リクエストの処理は変更していません。private準備器の明示的な`allow_physical_interrupt=True`から、正本とGPUに同じliteralなcamera／aim_interrupt環境設定を渡します。CPUで計算した照準スケジュール・ダメージ・抽選結果をGPU入力にしていません。標準入口では従来どおり拒否し、真偽値以外の許可値も拒否します。

最初の12ケースではリトルマーメイドの割り込みworld2件に差を発見しました。2.05秒の命中閾値で正本は本体の「거품」を解除し、次の射撃は12138になります。GPUは物理interruptを名前付き状態の参照先にして旧倍率を残し、12751となっていました。保存rawと元native指紋を照合して切り分け、CPU基準は変更していません。

修正は`world_actor_fields.slang`と`world_actor_state.slang`の4箇所です。物理着弾先を保ちながら、敵効果の選択・名前付き状態・boss/add条件ではpart／private interruptを本体へ対応させます。private kind6へcanonical hit creditを付けたり、ActorKind2を変更したりしません。厳密な逆投影ledgerで変更範囲を固定し、既存の数値演算・binary64・整数・pow・normalizerを維持します。

共通CLIに`aimed-enemy`6ケースを追加し、マーカー解除・runtime条件付き置換・boss/add条件をMetalで検証しました。`aimed-rosters`の12ケースも修正後に一致しました。全6624射／11870 returned packet／3532直接private着弾／9102抽選観測は正本契約です。実編成比較はキャラ別損傷・HP／cover・武器時計・バースト状態とtrace、pool全行／会計、最終照準、全順序付きRNGと最終MTを検査します。GPU射撃履歴は既存容量770を維持し、超過数も比較します。3532着弾や11870 returned packetの全行をGPUで個別traceしたという意味ではなく、全スキル発動列の観測もこの実編成比較器には未収録です。

`aimed-area-retention`の既存1405入力と`aimed-callback`20の保持検査は、同じ修正sourceで行います。全suiteの独立sealに成功しました。旧1405の全4419747840byteとcallback20の62914560byteは全byte一致です。CPU回帰95群498検査が175.984秒、最終の固定packageのCPU7群71検査も成功しました。詳細はcheckpointを参照してください。別々のbatchを単一実行の証拠として扱いません。既存のraw・失敗・claimは保持し、容量確保は成功済みの保存raw3ファイルを同じSHA／path／inodeのまま疎化し、6941179904byteの零割当を回収しました。データ削除はありません。

通常条件の全266プロファイルは既存監査器を再利用して旧9a497c7と比較し、組める230／base170の全入力SHAと、拒否36の理由を保持しました。これは静的packing証拠であり、230キャラのGPU実戦対応数ではありません。

同梱JSON不足による最初のCPU停止も保持しています。この経験を反映し、共通CLIの実行順を単体検査→正本CPU参照→GPU claim／起動へ変更しました。失敗時は高価なnative戦闘とGPUを開始しないこと、成功した単体検査だけではnativeゲートを省かないことを故障注入で確認しています。同一live parentの参照再利用は維持し、独立sealでは再計算します。

全suiteはdevelopment_only、全キャラ認定0、通常画面CPUです。固定のbase profile3つ・座標off・3／30秒の証拠から全カタログ、全variant、混在summonや全特殊効果へ昇格しません。Windows追加操作0、プロセス消失は原因unknown／保全false、現在sourceのCUDA実行一致は未確認です。次は全定義カタログへの対象world適用を広げ、残りの未対応consumerと制御経路を優先します。
