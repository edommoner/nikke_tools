# 共通着弾記録の圧縮

ABI `0x50455658` の作業中です。前段の機能認証は固定ソース `431d699`、証跡保存コミット `60c53bc` のABI `0x50455657` です。現在の圧縮版について、CUDAと実編成の最終認証・性能測定はまだ完了していません。全キャラ・全特殊効果の目標も継続しています。

着弾キューは最大2048件を維持し、1件を12→8ワードへ圧縮します。入出力の既存ブロック位置、入力77824ワード、私有Runtimeのフィールド、効果・イベント・数値計算を維持します。出力は98304→90112ワードで、1プログラムあたり32768バイト（出力全体の約8.3%、キュー本体の約33.3%）を削減します。これは配置上の削減であり、実行速度の改善を示す値ではありません。

| ワード | 内容 |
| --- | --- |
| 0 | 定義行8bit、継承対象3bit、保持mask9bit（動的選択は256） |
| 1 | 対象順序32bit |
| 2–3 | 捕捉ダメージのbinary64全ビット |
| 4–5 | 発動時刻のbinary64全ビット |
| 6 | 命中番号9bit、総命中数9bit、深さ6bit |
| 7 | 出現世代31bit |

整数は格納前に値域を検査し、行256・対象8・不正mask・0/257ヒット・深さ0/33・世代上限超過を拒否します。量と時刻をfloatへ変換しません。回復・対象選択・分割丸め・子通知順は前段と同じです。

`gpu/benchmark_landing_wide.slang` は同じ物理処理・同じ値域検査を12ワード配置で実行する制御版です。`research/verify-landing-compact.py` は259正例・11拒否のcodec検査と、全共通回帰入力を両配置でGPU実行します。表現だけを正規化し、使用済みの履歴を含む2048レコードすべてと、残りの全出力ワードを比較します。終了時排出をしない入力でも、生存キューのホスト読み戻しを確認します。CPUの途中状態・着弾予定表はGPUへ渡しません。

`research/benchmark-landing-compact.py` は全検証・Windows転送終了後だけに順次実行します。2件の着弾を持つ64プログラムと、2048件を持つ16プログラムを別々に測り、warm-up1回後の3標本を保存します。デスクトップGPU活動は除外できず、全編成の速度改善とは扱いません。
