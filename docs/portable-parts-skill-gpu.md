# 部位スキルの生成・receipt・着弾接続

`hits_parts`の非座標経路を共通Slangへ接続しました。生成時にlive部位のreachを検査し、取得済みの同じダメージ因子から本体値と部位値を作ります。静的has_partsだけの場合は本体へ部位補正を一度適用し、reach部位がある場合は本体の部位補正を外します。コアは部位値へ持ち越しません。

スキルFrameのcursor0でcoefficientを消費した後、healthValueを部位値のsnapshotとして使用します。後続hitと名前付き子イベントの復帰後も同じ値を使い、再照会しません。receiptの部位値は出力word781328〜785423の2048件×2wordに保存します。周期packetが使うat+7、周期38wordの対象snapshot、回復分配の診断log、最後の16word診断領域とは重複しません。slot再利用時はゼロも書き込み、前の値を残しません。

本体のgate・着弾・吸血の後、着弾時点でliveな部位だけを選びます。既存の物理部位処理を`deliverCounterPartGroup`へ共通化し、部位群のHP適用とgenerationを保持した後にcounter・吸血のcallbackを実行します。部位値はキャラtotalへ加えます。余分な名前付きhit通知やburst gaugeは発行しません。DoT部位の通知も本体と同じ`WORLD_PERIODIC_FAMILY`を使用します。

CLIの`parts-skill-world`は26入力（native25・deferred拒否1）です。元のCPU参照32ケースは残し、interrupt Actorの入力作成が未対応の7件を別途host拒否として検査します。DoTの部位カウンタ1ケースを追加し、正本のpart Actor・DoT family・3000damageによるthreshold完了を確認します。既存の全battle状態、generation、部位extra credit、回復、counter、skill traceを比較します。profiling専用の詳細lifecycleストリームをGPUの完全trace認定に置き換えるものではありません。

`skill-part-codec`は先頭・中央・最終slot、再利用時のゼロ・符号bit、周期at+7のsentinel、容量外2048の拒否を4入力で検査します。既知のsummaryだけでなく全出力wordと隣接領域のゼロも比較します。

初回25入力は同名再出現のgraph状態1項目だけで失敗しました。全native観測器が固定0にしていたcleared項目を、既存scheduler観測器と同じ実Runの終了述語へ修正しています。正本の計算やpinned upstreamは変更していません。CLIの明示的な`replay --reference-migration parts-cleared-v1`は、指定した2観測ソースSHA、1ケースのgraph_states[0][6]の0→1、他の全native fieldと全baselineの一致を要求します。通常replayの同一基準検査は維持し、別項目・別入力・別GPUソース・別observer変更は拒否します。元失敗とrawを保持し、保存rawの再監査・sealはGPU再実行0で成功しました。

その後のレビューでDoT部位のfamily共通化を追加しました。修正前の25入力実証と、DoT専用カウンタを含む最終26入力は別packageです。証拠と最終回帰の状態は`research/portable-parts-skill-gpu-checkpoint.json`に記録します。

最終sourceは旧849（native676・拒否173）と実編成4もMetal全件一致・独立seal済みです。旧849の2,670,723,072byte（89afa4ed...）と旧4の12,582,912byte（f83a45b0...）は全byte一致、全入力・native・出力entriesも保持しています。CPU集約308件は失敗0件。共通include追加でfull source閉包は112、commandsは113ですが、Runtime stride138952は維持しています。これらは実CUDA数値一致・速度改善の証明ではありません。

interrupt・座標・deferred burstの部位packetは未対応です。World descriptorは未対応のreach/interrupt組合せやpendingを拒否し、bodyだけを成功扱いにしません。静的packing218/266・base158/203はGPU実戦認定ではなく、全キャラ認定0・通常UI CPUです。Windowsは既存7プロセス終了の原因不明により追加実行を停止しています。CUDA／Metal両生成は同じ数値・効果・ケースを使用しますが、現ソースの実CUDA数値照合は未完了です。
