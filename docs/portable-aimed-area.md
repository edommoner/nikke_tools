# 狙った部位・割り込み対象への貫通／爆発着弾

共有Slangの武器継続処理へ、本体packet→狙った対象packetの順を接続しました。発射時に対象倍率を固定し、着弾callback後にダメージを再照会しません。本体側の周辺部位／割り込み配信では狙った対象を除外し、重複を防ぎます。散弾・複数銃口・死亡対象・吸血・周辺対象と射程拡大を含む12ケースです。

共通CLIの`reference --suite aimed-area`は正本60射／172 returned packetを固定します。Metalでは全battle・skill trace・HP／pool・割り込み合計／extra会計と、直接private着弾74行を照合しました。172行すべてをGPUで個別traceしたという意味ではありません。診断は36着弾のケースを縮めず、排他的bankへ移して容量16→128へ拡張しました。query／heal／IRQの同時診断は拒否し、Runtime138952byteと出力stride786432wordは維持します。

Metal全1405入力（native1121／拒否284）と診断12が成功し、保存rawをGPU再実行なしで独立監査し、両suiteをsealしました。旧1393入力のinput／native指紋は全保持。1387出力は全byte一致し、混在query6件はNQR header+8（成功cache hit数）の各3減少だけです。新しい発射時snapshotで重複したcache読出しが消えた差で、他の全byteは保持しています。診断bank外37551360byteも通常12と同一です。厳密normalizer・binary64・整数／pow・正本CPUの変更はありません。

最初のfull v1はCPU故障注入テストで停止し、GPU未起動でした。移動前の履歴source文字列を最新sourceへ直接replaceしても変化しないテストを、上位層を逆投影してから改変し、実際に一箇所変わったことを確認する検査へ修正しました。失敗package/captureは保持し、GPUコードとnative goldenは変更せず別v2で検証しました。CPU95群498検査は175.857秒で成功。最終の固定packageによるCPU7群33検査も成功しました。GPUは10.967秒でした。

通常入口への広いpromotionは行わずdevelopment_onlyを維持します。全キャラ認定0、画面CPU、目標未達です。次は本体／対象間のcallbackによる状態変化と全定義実編成の対象worldを追加します。Windowsの追加操作は0。ゲーム／動画の併用だけでは7プロセス消失の原因を確定できないため、原因unknown／保全falseを維持し追加検証を停止しています。現在sourceのCUDA数値一致は未確認です。
