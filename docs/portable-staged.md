# 段階適用と周期DoTの共通実行器

ABI `0x50455655`。同じSlangとfixtureをCUDA／Metalへ渡します。CPUの段階予定表はGPU入力に含めません。武器変更・散弾・バースト再突入を含む既存ケースも同じ共通回帰に残します。

親攻撃の回数を登録時に固定し、`start + (index + 1) * gap` のbinary64演算で段階時刻を計算します。同時刻は登録順です。遅れたフレームでは到来した段階を観測時刻で処理し、更新・解除後の古い登録を再実行しません。途中の固定ダメージ用スタックと、常駐DoTの実スタックは分離します。最終段階に寿命と通常周期の開始を結び付けます。

親の回数は0〜64、間隔は1μs〜60秒、後続周期の待ちは0〜3600秒です。0回は登録と発動回数消費を省略します。1フレーム4096段階を超える再帰的な仕事は明示的に失敗します。敵の選択・保持・出現世代は既存の共通周期処理を使います。全キャラ・全特殊効果の認証を意味しません。

独立CPU参照の周期ダメージコールバックでは、資源数を実際のダメージ時刻で評価するよう時計を保存・復元しました。遅延フレームで期限内の最後の周期を処理するとき、観測時刻の資源数を誤用していたケースを12,000ダメージとして固定しています。例外・入れ子・ハンドラー解除も単体検査します。

Metalの共通回帰は1027正例・171拒否、うち段階適用23件です。Windowsの今回の検証状況は最新のcheckpointを確認してください。実着弾時刻には既存の近似があるため、APIは `MODEL_WARNING` を返します。通常画面のCPU選択と全変種認証0/203体は維持します。
