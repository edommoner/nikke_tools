# 所持キャラ一覧・部隊表示の追加要望

状態：要望整理（未実装）。作成 2026-11-05。

## 要望

1. 所属・属性・バースト段階をアイコンで表示し、アイコンを押して絞り込みを切り替えられるようにする。
2. 選択中のキャラ、またはすでに設定されている部隊とシナジーのあるキャラに絞り込めるようにする。
3. 部隊内のシナジー効果を強調表示する。

## 現状

| 項目 | 現状 | 出典 |
|---|---|---|
| バースト段階 | 文字ボタン（すべて／Ⅰ／Ⅱ／Ⅲ）、単一選択 | `web/index.html` `#burst-filter` |
| 武器 | プルダウン、単一選択 | `#weapon-filter` |

| シナジー | 表示・絞り込みともになし | — |

所属は上流データ `parsed_nikke.json` に `manufacturer`（ほかに `class`、`squad`）があり、`catalog()` に追加するだけで取得できる。

## 1. アイコンによる絞り込み

- 対象：所属（エリシオン／ミシリス／テトラ／ピルグリム／アブノーマル）、属性（風圧／水冷／灼熱／電撃／鉄甲）、バースト段階（Ⅰ／Ⅱ／Ⅲ）。
- 並び：一覧上部にカテゴリごとのアイコン列を置き、プルダウンを置き換える。
- 選択の規則：同じカテゴリ内は複数選択でOR、カテゴリ間はAND。何も選ばないカテゴリは「すべて」。
  例：水冷＋電撃、かつバーストⅢ。
- 各カテゴリに「解除」を付け、全解除は既存のリセットに含める。
- キャラカードにも所属・属性・バースト段階の小アイコンを付け、絞り込みのアイコンと同じ見た目にする。
- 段階が切り替わるキャラ（`burst_stage` が単一でないもの）は、該当するすべての段階で表示する。

## 2. シナジーのあるキャラの絞り込み

### 基準

- 基準を選ぶ：「選択中のキャラ」または「編成中の部隊（空でない枠すべて）」。
- 一覧に「シナジーのあるキャラ」の切り替えを置き、1の絞り込みと併用できる（AND）。

### 判定方法

`docs/team-search-design.md` の方針どおり、シナジー表を手作業で作らず、効果データ（`parsed_skills.json`）の対象指定と条件から自動で導く。

| 種類 | 効果データの例 | 判定 |
|---|---|---|
| 基準側が候補を強化する | `allies_code:수냉`、`allies_weapon:SG`、`allies_class:화력형`、`allies_code_weapon`、`allies_squad`、`allies_burst_casted_burst3` | 候補の属性・武器・クラス・部隊・段階が対象に合う |
| 候補が基準側を強化する | 同上（候補のスキル） | 基準側の誰かが対象に合う |
| 編成条件で発動する | `squad_ally_exists`、`has_defender_ally`、`no_burst1_ally`、`no_defender_ally` | 候補を加えると条件を満たす（否定条件は満たさなくなる側も表示） |
| 特定キャラを名指しする | 対象がキャラ名（例：`"이사벨"`） | 名指しされたキャラと、名指ししているキャラ |

判定に含めないもの：

- `all_allies` など全員が対象の強化。誰と組んでも同じなので、絞り込みの根拠にはしない。
- `allies_top_atk` のような戦闘中の数値で対象が決まるもの。編成だけでは判定できないため、別の扱い（「対象になりうる」表示）を検討する。

各候補には、該当した理由を短い表示で添える（例：「水冷の味方を強化 ← ○○」）。

### 範囲外（後の段階）

詳細シミュレーションで「加えたときのダメージ増分」を測ってシナジーの強さを並べる機能は、計算時間がかかるため別の段階とする。ここでの絞り込みは「効果がかみ合う」ことの判定で、強さの順位ではない。

## 3. 部隊内のシナジーの強調表示

- 部隊の各メンバーに、2の判定で成立している関係をチップで表示する（例：「→ 水冷を強化：2人」）。
- メンバーにカーソルを合わせる（タップする）と、そのメンバーが強化する相手・強化を受ける相手の枠を強調する。
- 対象がいない効果は「対象なし」として薄く表示する（例：水冷強化があるが水冷の味方がいない）。
- 部隊にバーストⅠ／Ⅱ／Ⅲがそろっているかを部隊見出しに表示する。

## 決定事項（2026-11-05）

1. アイコン画像：顔画像と同じ配信元に従う。
2. 武器：文字のアイコン（AR／SMG／SG／MG／SR／RL）にして、同じアイコン列に並べる。
3. 強調表示：グラフィカルな表示を複数用意し、切り替えられるようにする（枠どうしを線で結ぶ、関係ごとに同じ色の丸を付ける、など）。
4. 戦闘中の数値で対象が決まる効果（`allies_top_atk` など）も含める。
5. 全員が対象の効果（`all_allies`）も含め、関係を次の3段階に分ける。絞り込みでは段階を選び、「すべて」では関係の件数順に並べる。
  上流データでは206体中112体が全員対象の効果を持つため、そのままでは絞り込みにならない。
  | 段階 | 内容 | 例 |
  |---|---|---|
  | A 条件一致 | 対象が属性・武器・クラス・部隊・名指し・編成条件で決まる | `allies_code:수냉`、`squad_ally_exists` |
  | B 恩恵が偏る全体効果 | 全員が対象だが、効く能力を持つキャラが限られる | 貫通ダメージ（貫通持ち）、チャージ速度・ダメージ（チャージ武器）、最大装弾数・リロード、分割・爆発ダメージ |
  | C 誰にでも効く全体効果 | 攻撃力・攻撃ダメージ・会心・回復など | `atk_pct`、`atk_dmg_pct`、`heal_hp_pct` |
  Bは「能力→恩恵を受ける性質」の小さな規則表（能力ごとに1行。キャラの組ごとではない）で判定する。
  既定はA＋Bで絞り込み、Cを含めるかは切り替えられる。Cは理由表示と部隊の強調表示に含め、強調表示では全員への線ではなく「全体」の印でまとめる。

6. シナジー判定の基準は、編成中の部隊のメンバーから選ぶ。
   - 部隊の各メンバーに「基準」の切り替えを付ける。枠を押して入れるキャラを選ぶ既存の操作とぶつからないよう、カード上の小さな印で切り替える。
   - 誰も基準にしていなければ部隊全体のシナジー、1人以上を基準にすればその人たちとのシナジーで絞り込む。基準は複数選べる。
   - 複数を基準にしたときは、基準の誰かとシナジーがあれば表示し（OR）、シナジーのある基準の人数が多い順に並べる。理由表示には、どの基準と関係があるかを出す。
   - 基準は部隊ごとに保持し、メンバーを外したら基準からも外す。部隊が空なら絞り込みは無効にする。
   - 部隊にいないキャラを基準にしたいときは、一度部隊に入れる。

## 進め方（Claude–Codexワークフローの単位）

1. カタログに所属を追加し、アイコン絞り込みとキャラカードのアイコンを実装する。
2. 効果データからシナジー関係を抽出する処理（サーバー側）と、そのテスト。
3. シナジーの絞り込みと理由表示。
4. 部隊内のシナジー強調表示。
