# 敵スケジューラーから共通被弾処理への接続

2026-10-21。新しい敵世界処理は別コピーの共通実行器で検証中です。通常の共通本体はソース `7357045`／ABI73のままで、敵世界の公開受付・全変種認証0/203・通常画面CPUを維持します。

## 接続した実行順

`world_frame_addresses.slang` と `world_frame_runtime.slang` を、共通のevent／combat／protection／target実行器へ接続しました。CUDAとMetalの計算・入力・検証は同じSlangとPythonを使います。バックエンドごとの敵攻撃実装は作りません。

開始前にスケジューラーの0秒処理を行い、battle_startを発火します。各GPUフレームではグラフ遷移を確定し、tickの期限処理を行った後、回収した攻撃を既存の被弾フレームへ渡します。対象選択はこの時点のHP・挑発・隠密・攻撃力・乱数状態を使い、保護・分配・HP・戦闘不能・被弾通知・その子イベントまで同じ実行器で処理します。その後に着弾・バースト・味方射撃が進みます。

入力コマンド番号に依存していた被弾入口を、コマンド定義・ダメージ値・対象規則・対象記録・受領者記録のアドレスに分けました。通常コマンドは旧アドレスを保持し、スケジューラーからの攻撃はパターン定義を読み、対象記録を1024・受領者記録を2048まで順次割り当てます。分配の受領者も別レコードです。単なるパターン番号の再利用で過去の被弾を上書きしません。超過時はstatus2で拒否し、成功した戦闘として切り詰めません。

別コピーの仮ABIは74、入力88848／出力225280 wordsです。基本入力は元の86016 words、その後にグラフ2320と32パターンの被弾定義を置きます。出力は旧159744 wordsを維持し、追加65536 wordsにグラフ状態・履歴・対象・被弾記録を格納します。Runtime／Frameの私有配列は増やしません。GPU入力はパターンと3コマンド（時計の進行・着弾排出・照会）で、72発・512発でもCPUで攻撃時刻や対象を生成しません。

## 確認した範囲

元の完全な`timeline.simulate`をGPU読み戻し後に実行し、20成功条件で各人ダメージ・HP／最大HP／割合／防御・遮蔽物・射撃数・残弾・順序付き被弾全項目・開始／終了／戦闘不能ログ・グラフ全状態／終了履歴・MT19937全624語と消費数が一致しました。参照側で置き換えるのは手で指定した効果・基礎値・武器データと観測用の薄いラッパーだけで、スケジューラー・対象選択・被弾計算・武器tick・フレームループを使います。

開始前の被弾で自分の射撃が止まる、装填中の遮蔽物、同フレームの被弾通知が次の攻撃を変える、未発射分の期限破棄、循環、72発の連続攻撃、同時512発のrandom:3を含みます。512発では1536受領者・2522乱数語を消費し、MT境界を複数回またいでも全状態が一致しました。別の2条件は対象記録1024・受領者記録2048での明示拒否と、処理完了した被弾の元CPUと同一の接頭辞を確認します。拒否条件を成功戦闘の全状態一致へ読み替えません。

0.2秒付近は逐次加算の時刻が`0.19999999999999998`になるため、元の0.2秒効果がまだ有効な境界をそのまま検査します。別の入力では0.1秒効果の`event:state_end:temp`で攻撃力順位を変え、通知が0.2秒付近の敵対象選択より先に届くことを確認します。通知名の最初の誤記はホストでGPU投入前に拒否され、正しい入力だけをGPUで実行しました。

旧4682入力は有効ABI73だけ74へ更新し、意図的な不正ABI70／71／72と他の全入力を保持しました。旧出力159744 wordsは全4682入力で完全一致し、追加領域もゼロです。新しいworld入力の不正値25ケースをGPUで拒否しました。入力契約の追加3単体を含む全285単体が成功しています。

最初の17条件では、開始ログをnullと展開した点と、GPUの戦闘不能フラグを表示ログへ展開しなかった点で比較に失敗しました。入力・raw・失敗した全展開JSONを保持し、展開処理だけを修正しました。GPUソースと入力の全byteが同じ保存出力をCPUで再照合し、GPUの変更なし再実行は行っていません。戦闘不能ログはGPUの被弾フラグとGPUの配送位置から作り、CPUの結果を補いません。

証拠は`portable-world-frame-metal.json`、`portable-world-frame-extended-metal.json`、`portable-world-frame-expiry-metal.json`、`portable-world-frame-prior-metal.json`です。全バッチの入力とreadbackは比較前に保存しています。
