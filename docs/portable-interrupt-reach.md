# 共通実行器の非座標skill到達処理

共通Slangでpierce／explosionの部位・interrupt到達を接続しました。通常UIとcanonical CPU／legacy CUDAは維持します。物理武器のinterrupt追加着弾、座標、deferred burstの参照モデル制約、実CUDA照合は未完了です。全キャラ認定を行う変更ではありません。

生成時のstatsを一度取得し、既存9因子と同じ取得値からintercept用の第5因子を保存します。コアなしの第3因子を再利用し、部位補正を外してintercept補正を一度加え、7因子の乗算順・整数化・最低1の境界を維持します。本体／部位の比から逆算しません。範囲の拡張statは既存のplainQuantityで必要な場合だけ生成時に読みます。旧single-value呼出しでは新たな範囲問い合わせを行いません。

ローカルFrameに生成済みinterrupt値とreachを保持します。named hitやHP子処理の後でも再計算せず、後続hitへ同じ値を渡します。Runtime／RootParamsのfieldは増やしていません。両reflectionのRuntime strideは138952byte、CUDA定数は48byteです。CUDAのstack・性能改善を示す値ではありません。

reachのあるpacketだけが、独立検証済み38wordの7bit codecを使います。at+7のhigh bitが版付きpacketを識別し、low部のindexは実際のlanding slotと一致する必要があります。周期のfrozen対象・membership・完全な32bit birth ordinalを保持し、通常packetやrandom最終tickの動的対象選択と区別します。codec検査後だけ読出し、届く部位はhits_partsなら5、その他は生成時のreachを使います。新しいreceiptがない旧world tierでは、従来の到達拒否を維持しています。

kind6のinterrupt groupはpart callbackの完了後にlive対象を取得します。対象別extra_hits／extra_dealtと5人別interrupt累計を更新し、breakable対象には余剰を切り捨てず全damageをHPへ適用します。hp0の壊れない対象はdealtを増やしません。全対象の破壊・score・通知を更新してから、返されたpacket数だけ既存の吸血／回復分配実行器を呼びます。キャラtotal、scoredDamage、direct hits／landed、typed impact／counter、ゲージには加えません。

5人別累計は既存part bank終端785424から10wordを使い、診断tail786416との間に収めます。slot別extraはpartとinterruptで別slotなので既存bankを共有します。入力には作者のkind／reach／HPなどだけを渡し、HP推移や着弾結果はnativeから供給しません。native観測器は実BossScript.finishの累計と実Run.Targetのextraを読み取り、GPUの専用累計／slot bankと直接比較します。

46入力（native41／拒否5）のMetal検証と独立sealを完了しました。従来拒否だった到達5入力に加え、回復子／named子でのintercept buff変更、複数interruptの破壊とscore、壊れない対象、周期3tick、共有吸血の6入力を追加しました。通常の全battle状態・healing・skill traceに加え、interrupt累計と対象別extraを比較します。新しいrandom最終tickの実入力での境界照合は別途必要です。既存のcodec154入力は表現の証拠であり、戦闘全体の証明として代用しません。

元の数値・wire fixtureは変更していません。Frame metadataの厳密な逆変換と、レビューしたsource SHAの有限台帳だけを監査器へ追加し、scope・型・式・bank位置・codec・callbackが異なる変更を拒否します。監査器の成功自体はGPU一致を意味しません。最終の回帰・raw保持と出所は`research/portable-interrupt-reach-checkpoint.json`へ記録します。
